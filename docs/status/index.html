01Overview

무엇을, 왜 만드는가

v0.1.0 · pre-alpha

macOS 메뉴바에 Claude Code · OpenAI Codex · OpenCode Go · Antigravity의 남은 사용량과 리셋 시각을 상시 표시하는 오픈소스 앱.

한도에 부딪힌 뒤에야 알게 되는 문제를 없앤다. 값이 없으면 없다고 말하고, 낡았으면 낡았다고 표시한다.

Blockers · 지금 막힌 것01
Blocker 01차단 요인

모델 폴백 체인 없음

oh-my-opencode-slim의 go 프리셋은 에이전트마다 단일 모델. 429 한 번에 해당 레인이 죽고 재시도/대체가 없음.

조치프리셋에 fallback 배열 추가 (oracle: glm→deepseek, designer/fixer: deepseek→glm)

성공 기준

v1
  1. 01실행 후 3초 내 첫 값, 30초 주기 갱신
  2. 02provider별 5시간/주간(또는 rolling/weekly/monthly) 잔여 %와 리셋 카운트다운
  3. 03실패 시 마지막 성공값 + stale 표시, 0%로 오표시 금지
  4. 04토큰·이메일 등 민감정보를 로그·크래시 리포트·이슈에 남기지 않음

Non-goals

v1
  • 비용 환산 대시보드 (v2 후보)
  • Windows/Linux, 팀 단위 집계
  • 대화 내용·프롬프트 수집
02Providers

네 개의 소스, 네 개의 파서

4 providers · 실측 2

provider마다 데이터 소스와 자격증명 취급 방식이 다르다. 단위와 리셋 포맷도 공유하지 않는다 — 파서를 하나로 합치면 한 provider의 응답 형식이 바뀔 때 나머지까지 함께 깨진다.

03Architecture

순수한 코어, 격리된 실패

Core는 UI를 모른다

Package.swiftmodule layout
Package.swift
├─ UsageCore (library, UI 무관)
│   ├─ Models/     UsageSnapshot, LimitWindow, ProviderStatus
│   ├─ Providers/  ClaudeCode · Codex · OpenCodeGo · Antigravity
│   ├─ Auth/       Credential(redacted), Keychain/파일 스토어
│   ├─ Net/        HTTPClient 프로토콜 + URLSession 구현, RetryPolicy
│   ├─ Schedule/   actor PollScheduler (provider별 독립)
│   └─ Storage/    SnapshotCache (temp → rename 원자적)
└─ UsageApp (SwiftUI, MenuBarExtra + 팝오버)
설계 원칙
01

Core는 순수 — 네트워크/키체인/시계를 프로토콜로 주입해 fixture만으로 테스트

02

provider 실패는 앱 실패가 아니다 — 카드 단위 독립 상태

03

파서는 공유하지 않는다 — 단위 2종, 리셋 포맷 4종

04

UI 스레드에서 네트워크/키체인 접근 금지

폴링 전략

provider별 최소 60초 (Claude 180초, Antigravity 300초), 지수 백오프 60s→2m→5m→15m→30m, Retry-After 존중

테스트 전략

./Scripts/test-local.sh가 로컬 게이트. CLT 환경의 swift test는 테스트를 실행하지 않고 exit 0 하므로 신뢰 금지.

04Security & legal

읽기만 하고, 남기지 않는다

HIGH 2 · MEDIUM 2

핵심 비대칭

자격증명을 읽는 provider는 Claude Code 하나뿐. Codex/Antigravity는 CLI를 실행해 출력만 읽고, OpenCode Go는 자기 API 키를 쓴다.

네트워크 allowlist

  • api.anthropic.com
  • chatgpt.com
  • opencode.ai

이 도메인 밖으로 나가는 요청은 만들지 않는다.

정책

  • 토큰은 메모리 전용 — 디스크 복사·로그·크래시 리포트 금지
  • Redacted 래퍼 + os.Logger privacy .private
  • 토큰 refresh 금지 (1회용 회전이 원본 CLI를 깨뜨림)
  • CI가 Sources/의 하드코딩 토큰과 allowlist 밖 URL을 모두 실패 처리
  • 샌드박스 비활성 → Mac App Store 배포 포기 (README에 명시)
리스크
HIGH

비공식 엔드포인트 변동 — 계약이 아니라 관측. 파서는 fixture로 고정하고 폴백을 유지

HIGH

Anthropic 자격증명 정책 — 옵트인 + 메모리 전용 + 원격 철회 가능성 명시

MEDIUM

계정 제재 가능성 — 간격 하한 + 백오프 + 사용자 고지
