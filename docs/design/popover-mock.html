04

Notes

Why the artifact looks like this, in four decisions that are easy to undo by accident.

The meter is remaining, not usage

The big number and the bar must read the same direction. A 98% remaining row is a 98% full bar; the wall is an empty bar. The 15% notch makes the warning zone physical, so it still works for a colour-blind reader.

Failures keep their numbers

A failed refresh swaps the status, never the last-good windows. The card shows Stale · 4m ago and a still-honest value. With no last-good value, it shows a named state and a way out, not 0%.

The menu bar is stricter than the card

There is no room for "stale · 4m" in 12 pt. A recent stale value gets a ~; a failed or older-than-30-minutes value is omitted. The popover always has the full story.

Consent is a control, not a modal

Claude's login read is off, explained in one sentence, and attached to a CTA that works without it. No pre-checked box, no "recommended", no second prompt after dismissal.
